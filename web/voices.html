Qwen3-TTS voices designed from a description

The 1.7B VoiceDesign model renders a reference clip from your description. The 0.6B and 1.7B clones copy that clip, so one consistent voice reads the whole paper. 1.7B-design applies the description to every sentence: it follows the description most literally, but the voice can drift between sentences. Design is random, so a new take of the same description is a different voice.
